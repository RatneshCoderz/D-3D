# Defence Evolution 3D

A browser-based 3D survival shooter built entirely using:

- HTML
- CSS
- JavaScript
- Three.js

Play online:

https://ratneshcoderz.github.io/D-3D/

---

## Features

- 3D open world
- Third-person gameplay
- Weapon shop
- Multiple guns
- Enemy waves
- Inventory system
- Buildable defenses
- Mobile controls
- Desktop support
- Survival mechanics
- Minimap
- Custom skins

## Controls

### PC

W A S D = Move

Mouse = Camera

Space = Jump

### Mobile

Joystick = Move

Touch controls = Actions
